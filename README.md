# E-Commerce Store

## Overview

A web-based e-commerce application built with PHP 8.2+ and Laravel 11. It uses Livewire to create dynamic interfaces and integrates various tools and libraries for authentication, localization, data management, caching, and real-time communication.

## Technologies & Tools

- **PHP 8.2+**
- **Laravel 11**
- **Livewire 3**
- **Laravel UI**
- **Laravel Sanctum**
- **Bootstrap 5**
- **jQuery & AJAX**
- **Laravel OTP**
- **No CAPTCHA**
- **Laravel Localization**
- **Laravel Translatable**
- **Eloquent Sluggable**
- **Laravel DataTables**
- **Redis**
- **Laravel Cache**
- **Pusher & Laravel Echo**
- **PHP Flasher**
